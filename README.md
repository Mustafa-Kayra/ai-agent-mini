# AI Agent Mini

Puter AI'ın sadeleştirilmiş mini versiyonu. En popüler yapay zeka modelleriyle basit sohbet.

## Özellikler

### 🤖 4 Popüler AI Modeli (OpenRouter Üzerinden)
- **ChatGPT (GPT-4o)** - `openrouter:openai/gpt-4o`
- **Kimi k2** - `openrouter:moonshotai/kimi-k2`
- **Gemini 2.5 Flash** - `openrouter:google/gemini-2.5-flash-preview`
- **Claude Sonnet 4** - `openrouter:anthropic/claude-sonnet-4`

### 🌍 11 Dil Desteği
1. 🇹🇷 Türkçe (Varsayılan)
2. 🇺🇸 English
3. 🇨🇳 中文 (Çince)
4. 🇮🇳 हिन्दी (Hintçe)
5. 🇪🇸 Español (İspanyolca)
6. 🇫🇷 Français (Fransızca)
7. 🇸🇦 العربية (Arapça)
8. 🇧🇩 বাংলা (Bengalce)
9. 🇧🇷 Português (Portekizce)
10. 🇷🇺 Русский (Rusça)
11. 🇯🇵 日本語 (Japonca)

### 💬 Konuşma Stilleri
- Normal - Profesyonel
- Z Kuşağı - 🔥💀 Argo
- Y Kuşağı - Nostaljik
- Akademik - Bilimsel
- Samimi - Arkadaşça
- Özel - Kendi Stilin

### 🖼️ Resim Oluşturma
- Nano Banana modeli ile resim oluşturma
- Resim yükleme ve analiz

## Kullanım

1. `index.html` dosyasını bir tarayıcıda açın
2. Sağ panelden dil ve model seçin
3. Sohbete başlayın!

## Teknolojiler

- **Puter.js** - AI API entegrasyonu
- **Tailwind CSS** - Styling
- **Lucide Icons** - İkonlar
- **Marked.js** - Markdown parsing
